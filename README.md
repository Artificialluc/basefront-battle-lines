BASEFRONT: BATTLE LINES

This folder is ready to publish as a static website.

Easiest publishing method: GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new public repository, e.g. basefront-battle-lines
3. Upload index.html
4. Open Settings -> Pages
5. Under Build and deployment, choose Deploy from a branch
6. Select branch main and folder / (root), then Save
7. GitHub will give you a public website address.

The game is self-contained in index.html, so no server is required.
